# Fluent UI System Icons

Source: https://github.com/microsoft/fluentui-system-icons
Downloaded from the main branch on 2026-09-27.
License: MIT; see LICENSE in this directory.

Regular icons: Folder 20, Folder Open 20, Document 20,
Chevron Right 12, Chevron Down 12.
Toolbar: Arrow Left 20, Arrow Up 20, Arrow Clockwise 20, Arrow Download 20.
Action toolbar: Open 20 and Hard Drive 20 (Regular).
File types: Document Text 20, Image 20, Video 20, Music Note 2 20,
Folder Zip 20 and Code 20 (Regular). These also use white path fills for tinting.
PDF files reuse Document 20 with a red tint.
SVG files are embedded at compile time; no runtime network or icon font required.
Folder, Folder Open and Document path fills are normalized to white so the
application can tint them gold and blue without multiplying by the original dark fill.
